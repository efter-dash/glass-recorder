# Cyan Glass Recorder Lens

The user-supplied `Cyan Glass Recorder Lens.png` replaces the previous generated camera artwork. `icon-source.png` preserves the original 1254 × 1254 image unchanged. No AI redraw, recoloring, or cropping is applied.

- `icon.png`: 1024 × 1024 packaging master.
- `icon.icns`: macOS iconset, 16–1024 px representations.
- `icon.ico`: Windows PNG-backed entries at 16, 32, 48, 64, 128, and 256 px.
- `public/app-icon.png`, `app-icon-512.png`: standard and high-density UI artwork.
- `public/favicon.ico`: multi-size browser icon.
- `public/apple-touch-icon.png`: 180 px home-screen/bookmark icon.

Native sizes are generated with macOS sips/iconutil; ICO containers preserve the resized PNG representations. UI rounding and restrained cyan shadows are CSS-only, so the original artwork remains intact. Browser asset URLs are versioned to refresh cached icons.
